# 🤖 AI-Powered Personal Deadline Manager

> Turn messy reminders into organized action.

An AI-powered personal deadline management application that converts natural-language reminders into structured, prioritized, and trackable deadlines using Google Gemini AI.

Instead of manually entering a task title, category, priority, date, and description, users can simply type:

> "TCS placement registration closes tomorrow at 5 PM."

The application analyzes the natural-language reminder, extracts structured information, validates the result, and stores the deadline in a SQLite database.

---

## 📌 Overview

Managing deadlines across assignments, examinations, placement applications, projects, and personal tasks can become difficult when information is scattered across different sources.

This project provides a simple natural-language interface where users can describe a deadline in plain English.

The AI converts that input into structured information such as:

- Title
- Description
- Category
- Priority
- Deadline
- Date and time

The structured data is then validated and stored in the database.
